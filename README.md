# 🎨 CSS From Zero

Welcome to **CSS From Zero**! 🚀

This repository documents my journey of learning CSS from the fundamentals to more advanced concepts. It includes notes, code examples, practical exercises, and mini projects to help build a strong foundation in web styling.

My goal is to understand CSS step by step and improve my frontend development skills through consistent practice.

- CSS Introduction & Syntax
- Selectors & Combinators
- Colors & Backgrounds
- Text & Typography
- Box Model
- Margin, Padding & Borders
- Display & Positioning
- Flexbox
- CSS Grid
- Pseudo-classes & Pseudo-elements
- Transitions & Animations
- Responsive Web Design
- Media Queries
- CSS Best Practices
